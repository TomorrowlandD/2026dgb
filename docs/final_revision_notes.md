# 最终方案修订说明

## 1. 综合评估与选择

当前方案采用“保留现有阶段 0-6 结果、统一建模口径、修订方案文档和论文解释”的路线是可行的，也是当前推荐方案。

不建议推倒重跑的理由：

- 问题 1 已采用收费服务等比例削减，紧急救助未被消费约束削减；
- 问题 2 排序目标已经不含年化利润，主排序为覆盖率、有效覆盖率、满意度、需求满足率和建设成本；
- 问题 3 已实现价格反馈闭环，每组候选价格都会重新计算 `S3`、分配、有效服务人次、补贴和利润率；
- 问题 4 已对 S0-S4 执行完整重求解；
- 阶段 6 的 7 张核心图均来自现有结果表，当前不需要重画。

因此，当前选择的最终路线为：

```text
不推倒重跑主模型、不重画图
-> 仅对定价并列候选输出做一致性修复并刷新相关结果表
-> 修订 revised_modeling_plan.md
-> 补充最终一致性审查
-> 整理论文关键结果材料
-> 进入论文正文撰写
```

## 2. 保留的内容

- 阶段 6 的 7 张核心图；

- 利润率硬约束采用 `rho_topic <= 8%`。

## 3. 必须修改的表述

论文和方案文档中必须统一以下表述：

1. 不再把“刚需优先”写成主模型或核心创新点，只能作为补充对比或改进方向。
2. 问题 1 写成“收费服务等比例削减 + 紧急救助公益免费且不削减”。
3. 明确模型内部保留连续值，服务需求展示时再四舍五入取整。
4. 问题 2 不用年化利润作为主排序目标。
5. 年度利润只作为问题 2.3 基准价格下的测算指标。
6. 问题 3 明确定价反馈到价格满意度、分配、有效服务人次、补贴、收入、利润率和可及性。
7. 主定价模型采用统一服务价格 `p_k`；每站每服务独立定价只作为改进方向。
8. 题目利润率和年度净收益必须分开写。
9. 若某站点或某情景年度净收益为负，不能写成“完全财务可持续”，只能写成“存在保本风险”。
10. `CR_srv` 需要说明是小区聚合数据下的覆盖近似，并用 `CR_eff`、`DR` 补充说明覆盖深度。

## 4. 只有这些情况才需要重跑

仅当出现以下决策或错误时，才需要重跑阶段结果：

1. 决定把利润率硬约束改为 `0 <= rho_topic <= 8%`；
2. 决定做 Q2-Q3 联动筛选最终站点方案；
3. 发现结果表存在实质计算错误；
4. 将主定价模型改为每站每服务独立定价；
5. 论文要宣称所有站点均完全保本且财务可持续。

除此之外，当前结果和图表继续使用。

## 5. 写作时的关键解释

- 当前模型贴合题面，消费约束、服务半径、满意度、补贴和利润率均有题目或附件依据。
- 定价不是只改变收入，而是通过 `S3` 反馈到综合满意度、小区分配和有效服务人次。
- 预算提高不必然代表最终方案更优；如果扩张后年度净收益下降，应解释为服务效果改善伴随运营风险增加。
- 对亏损风险不回避，应提出区域统筹、专项补贴、站点规模优化等政策建议。
