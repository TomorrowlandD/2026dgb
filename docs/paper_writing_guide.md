# B题论文撰写指南

本文档用于把当前已完成的模型、结果表和图表转化为完整数学建模论文。它不是论文正文，而是写作顺序和引用材料清单。

## 1. 写作总原则

- 先写“模型建立与求解”和“结果分析”，最后写摘要。
- 所有数值只引用 `outputs/tables/`、`outputs/figures/` 和 `docs/paper_key_results_summary.md` 中已有结果，不补编未运行结果。
- 主模型口径以 `docs/revised_modeling_plan.md` 为准。
- 定价结果以 `outputs/tables/problem3_prices.csv` 为准。
- 题目利润率和年度净收益必须分开写。
- 有亏损站点或亏损情景时，只写“存在保本风险”，不能写“所有站点完全财务可持续”。

### 第二步：先写“模型建立与求解”

建议先写论文第 5 节，因为这一节决定全文公式和口径。

#### 5.1 问题 1：老人数量预测与需求修正

必须写清：

- 三类老人状态递推；
- 新增老人进入自理状态；
- 理论服务需求由老人类型人数和服务频次计算；
- 收费服务超过消费上限时等比例削减；
- 紧急救助为公益免费服务，不参与消费约束削减；
- 计算保留连续值，展示服务需求次数时再四舍五入。

建议引用：

- 图 1：三类老人五年预测趋势图；

- `outputs/tables/problem1_population_forecast.csv`；

#### 5.2 问题 2：服务站选址与规模优化

### 第三步：写“结果分析”

结果分析按问题 1-4 分段写，每段遵循同一结构：

```text
先给核心结果
-> 引用表或图
-> 解释为什么合理
-> 指出约束是否满足
-> 提醒风险或局限
```

必须覆盖的结果：

| 问题 | 必须写出的结果 |
|---|---|
| Q1 | 第 5 年老人总数、三类老人数量、实际月需求总量、紧急救助不削减 |
| Q2 | 建站方案 C 小型、D 大型、G 大型；建设成本 108 万元；`CR_eff=0.8530`；满意度 0.8622 |
| Q3 | 优化价格、年度补贴 226.30 万元、最高题目利润率 7.72%、C 站年度净收益为负 |
| Q4 | S1-S4 主要变化，特别是 S4 覆盖改善但年度净收益为负 |

### 第四步：写“模型评价与改进”

优点可以写：

- 口径贴合题目；
- 消费约束、服务半径、满意度、补贴和利润率均有附件依据；
- 选址采用枚举剪枝，结果可复核；
- 定价反馈到满意度和有效服务量；
- 灵敏度分析完整重求解。

不足必须具体：

- `CR_srv` 是小区级聚合近似，缺少个体级获得服务记录；
- 没有把 `rho_topic >= 0` 作为硬约束，亏损风险通过年度净收益解释；
- 主模型采用统一服务价格，未做每站每服务独立定价；
- 距离矩阵不是实际道路通行时间；
- 刚需优先只作为补充分析，未进入主模型。

改进方向可以写：

- 引入个体级服务记录或抽样调查数据；
- 做 Q2-Q3 联动筛选；
- 在政策要求更强时加入 `0 <= rho_topic <= 8%`；
- 引入每站整体浮动或每站每服务差异化定价；
- 用真实路网时间替代距离矩阵。

### 第五步：回头写前置章节

#### 问题重述

只重述题意，不加入结果。按四问写：

1. 预测老人数量和服务需求；
2. 选择服务站位置和规模；
3. 制定价格、补贴并评价可及性；
4. 做灵敏度分析。

#### 问题分析

写成逻辑链：

```text
老人数量变化决定需求
-> 消费能力约束修正需求
-> 需求和距离共同决定选址
-> 价格影响满意度和有效服务量
-> 补贴与利润率决定运营约束
-> 情景变化检验鲁棒性
```

#### 模型假设

建议包含：

- 附件数据真实有效；
- 五年内服务项目和服务频次规则不变；
- 小区内老人服务可用小区聚合数据近似；
- 紧急救助为公益免费服务；
- 建设成本按 20 年摊销；
- 服务半径按附件距离矩阵判断。

#### 符号说明

符号表不宜过长，优先列核心变量：

| 符号 | 含义 |
|---|---|
| `N_{i,r,t}` | 第 `t` 年小区 `i` 类型 `r` 老人数 |
| `D_{i,r,k}` | 小区 `i` 类型 `r` 对服务 `k` 的需求 |
| `E_{i,r,k}` | 容量调整后的有效服务人次 |
| `S1,S2,S3` | 距离、响应、价格满意度 |
| `CR_srv,CR_eff,DR` | 服务覆盖率、有效覆盖率、需求满足率 |
| `G_j` | 服务站 `j` 政府补贴 |
| `rho_topic` | 题目口径利润率 |
| `Net_j` | 年度净收益 |

### 第六步：最后写摘要

摘要最后写，控制在“方法 + 结果 + 结论”三层：

- 方法：马尔可夫状态递推、消费约束修正、枚举剪枝选址、定价反馈闭环、灵敏度重求解；
- 结果：第 5 年老人总数、最优站点方案、覆盖率、满意度、价格、补贴、利润率；
- 结论：方案覆盖较好，但存在局部保本风险，预算扩张需结合财政可持续性判断。

摘要中的每个数字都必须能在正文表格或图中找到。

## 3. 最容易写错的地方

| 易错点 | 正确写法 |
|---|---|
| 把刚需优先写成主模型 | 只写成补充对比或改进方向 |
| 把问题 2 年化利润写成排序目标 | 问题 2 按覆盖率、有效覆盖率、满意度、需求满足率、成本排序 |
| 把价格变化只影响收入 | 价格必须反馈到 `S3`、分配和有效服务量 |
| 混用利润率和年度净收益 | `rho_topic` 用于题目约束，`Net_j` 用于财务风险 |
| 写所有站点都财务可持续 | C 站年度净收益为负，只能写存在局部保本风险 |
| 写预算越高越好 | S4 覆盖改善但年度净收益为负，需要综合判断 |
| 把图 3 写成真实地图 | 图 3 是距离矩阵构造的网络分配示意图 |
