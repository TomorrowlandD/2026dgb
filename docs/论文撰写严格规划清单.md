# 论文撰写严格规划清单

本文档用于约束大模型逐步完成 B 题《嵌入式社区养老服务站的建设与优化问题》论文撰写。执行时必须按步骤推进，前一步检查未通过时，不进入下一步。每一步只生成指定内容，不一次性生成全文。

本文写作采用 **LaTeX 优先工作流**：先让大模型生成和维护 LaTeX 源文件，完成公式、图表、编号、交叉引用和参考文献；后续再由人工按 `docs/“电工杯”全国大学生数学建模竞赛论文Word模板.pdf` 或 Word 模板手动转为 Word。大模型不直接编辑 Word 终稿。

## 0. 总约束

### 0.1 必须使用的提示词

1. 正文写作提示词：
   `docs/数学建模竞赛论文写作提示词：B 题《嵌入式社区养老服务站的建设与优化问题》.md`

2. 摘要优化提示词：
   `docs/数学建模论文摘要优化提示词：B 题《嵌入式社区养老服务站的建设与优化问题》.md`

3. 提示词使用指导：
   `docs/论文撰写提示词使用指导.md`

4. 竞赛论文格式模板：
   `docs/“电工杯”全国大学生数学建模竞赛论文Word模板.pdf`

### 0.2 必须锁定的项目口径

1. 主模型采用“收费服务等比例削减”的消费约束需求调整。
2. 紧急救助公益免费，不参与消费约束、不计政府补贴，但计入直接成本和服务能力占用。
3. “刚需优先”只能作为补充对比、局限性或改进方向。
4. 问题 2 不使用年度利润排序。
5. 问题 3 每组价格必须反馈到 `S3`、分配、有效服务人次、补贴、题目口径利润率、年度净收益和可及性。
6. 利润率硬约束只保留 `rho_topic <= 8%`。
7. 年度净收益 `Net_j` 与题目口径利润率分开解释。
8. 三类老人可及性必须基于最终有效服务人次 `E_{i,r,k}`。
9. 问题 4 的 S0-S4 情景必须完整重求解。
10. 不编造任何数值、表格、图片或参考文献。

### 0.3 每一步通用执行格式

每次调用大模型时，输入应包含：

```text
本次执行步骤：【步骤编号和名称】
本次只生成：【目标章节或文档】
必须吸收的提示词内容：【列出本 planning list 中指定的提示词章节】
可用材料：【列出提供给模型的结果表、图表、方案或日志】
必须遵守的最终口径：【粘贴 0.2】
输出要求：【该步骤的产出格式】
禁止事项：【该步骤检查项】
```

每次输出后，先完成本步骤检查，再进入下一步。

### 0.4 模板结构要求

论文结构应吸收“电工杯”模板的组织方式，并与本项目内容适配。最终 LaTeX 文档按以下顺序组织：


模板中的“数据预处理”可放入 `5.1.1 数据预处理`，也可作为第五章开头的公共小节；本项目建议保留独立的 `5.1.1 数据预处理`，同时在问题一模型前说明清洗后的参数表如何支撑全部问题。

页面和分页必须满足以下要求：

1. 纸张为 A4。
2. 上、下、左、右页边距均为 2.5 cm。
3. 正文字体对应 Word 模板的宋体小四号字；LaTeX 中建议使用 `ctexart` 的 `zihao=-4` 或等价设置。
4. 第一页为封面页，只填写参赛编号和论文题目；论文题目使用赛题题目，不自拟。
5. 第二页为论文题目、摘要和关键词；摘要和关键词不需要英文翻译。
6. 页码从第二页开始，位于页脚中部，使用阿拉伯数字从 `1` 连续编号。
7. 第三页开始为论文正文，不生成目录。
8. 正文控制在 25 页以内；附录页数不限。
9. 正文之后依次放置参考文献和附录。

### 0.5 LaTeX 工作流要求

大模型编写论文时必须生成 LaTeX 源文件，而不是 Word 文档。建议文件结构如下：

```text
paper/
  main.tex
  refs.bib
  sections/
    00_cover.tex
    01_abstract.tex
    02_problem_restatement.tex
    03_problem_analysis.tex
    04_assumptions_symbols.tex
    05_model_solution.tex
    06_model_validation.tex
    07_model_evaluation.tex
    08_references_appendix.tex
```

LaTeX 写作要求：

1. 中文论文建议使用 `ctexart` 或等价中文 LaTeX 文档类，并设置 A4、2.5 cm 页边距和小四号正文。
2. 数学公式必须用 LaTeX 原生公式环境，不用截图。
3. 表格优先使用 `booktabs` 三线表风格。
4. 图表使用 `figure`、`table`、`\caption{}`、`\label{}` 和 `\ref{}` 管理编号。
5. 图像直接引用 `outputs/figures/` 中已经生成的核心图。
6. 公式编号、图编号和表编号必须可自动交叉引用。
7. 不在正文中写代码文件路径，代码路径放入附录或复现说明。
8. LaTeX 源文件中不得出现“AI 提示词”“由 AI 生成”等内部过程表述。
9. 若竞赛最终要求披露 AI 工具使用，应按赛题或模板要求由人工在参考文献或附录中统一处理；论文主模型表述不得出现提示词细节。

`main.tex` 至少应体现以下模板设置：

```latex
\documentclass[UTF8,zihao=-4,a4paper]{ctexart}
\usepackage[margin=2.5cm]{geometry}
\usepackage{amsmath,amssymb,booktabs,graphicx,float}
\usepackage{caption}
\usepackage{fancyhdr}
\usepackage{hyperref}

% 封面页不显示页码；摘要页开始显示页码 1。
\pagestyle{fancy}
\fancyhf{}
\cfoot{\thepage}
\renewcommand{\headrulewidth}{0pt}
```

封面和摘要页的页码逻辑必须在 LaTeX 中明确实现：

```latex
\input{sections/00_cover}
\clearpage
\setcounter{page}{1}
\input{sections/01_abstract}
\clearpage
\input{sections/02_problem_restatement}
```

其中 `sections/00_cover.tex` 使用 `\thispagestyle{empty}`，不得显示页码；从 `sections/01_abstract.tex` 开始显示页脚居中页码。

### 0.6 模板摘要要求

摘要必须控制在一页以内，采用模板建议的逻辑：

```text
开头段：交代研究背景、主要问题、总体模型路线和核心结果。
分问题段：针对问题一至问题四，分别说明建模方法、求解过程和真实结果。
收尾段：总结模型价值、适用范围、风险和改进方向。
关键词：3-5 个，使用分号分隔。
```

摘要中不得编造数值；所有结果必须来自正文、表格或图。

### 0.7 模板参考文献与附录要求

正文引用处必须使用方括号标示参考文献编号，如 `[1]`、`[3]`；同一处引用多篇文献时可写为 `[1][3]`。引用书籍时必须指出页码。参考文献按正文首次引用顺序排列。

参考文献按以下格式书写：

```text
书籍：[编号] 作者，书名，出版地：出版社，出版年，页码.
期刊论文：[编号] 作者，论文名，杂志名，卷期号：起止页码，出版年.
网上资源：[编号] 作者，资源标题，网址，访问时间（年月日）.
```

LaTeX 中可以手写 `thebibliography`，也可以维护 `refs.bib` 后再按上述格式导出；最终 PDF 和转 Word 稿必须呈现为模板要求的中文顺序编码格式。

附录应包括：

1. 支撑材料和输出文件列表。
2. 核心代码说明和运行顺序。
3. 必要的较大表格、补充流程图或详细计算过程。
4. 复现说明。

不要把大段无关代码塞入正文；代码说明和复现路径放入附录。
