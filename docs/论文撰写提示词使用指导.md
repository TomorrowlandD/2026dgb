# 论文撰写提示词使用指导

本文档用于指导大模型基于两份提示词辅助完成 B 题《嵌入式社区养老服务站的建设与优化问题》的论文撰写。使用时应以项目现有结果为唯一依据，不得脱离 `docs/revised_modeling_plan.md`、`outputs/tables/`、`outputs/figures/` 和检查日志自行扩展模型或编造数值。

## 一、可使用的提示词

1. 论文正文写作提示词：
   `docs/数学建模竞赛论文写作提示词：B 题《嵌入式社区养老服务站的建设与优化问题》.md`

2. 摘要优化提示词：
   `docs/数学建模论文摘要优化提示词：B 题《嵌入式社区养老服务站的建设与优化问题》.md`

第一份用于论文大纲、模型建立、结果分析、模型检验、模型评价与附录说明。第二份只在正文主体基本完成后使用，用于优化题目、摘要和关键词。

## 二、使用前必须提供的材料

每次让大模型写某一章节前，应至少提供以下材料中与该章节有关的部分：

1. 最终方案与口径：
   - `docs/revised_modeling_plan.md`
   - `docs/final_revision_notes.md`
   - `docs/final_consistency_audit.md`

2. 论文写作参考：
   - `docs/paper_key_results_summary.md`
   - `docs/paper_writing_guide.md`

3. 结果表格：
   - `outputs/tables/paper_problem1_*.csv`
   - `outputs/tables/paper_problem2_*.csv`
   - `outputs/tables/paper_problem3_*.csv`
   - `outputs/tables/paper_problem4_*.csv`
   - 必要时补充 `outputs/tables/problem*_*.csv`

4. 图表索引和图片：
   - `outputs/figures/figure_index.md`
   - `outputs/figures/fig1_*` 至 `outputs/figures/fig7_*`

5. 检查日志：
   - `outputs/logs/stage0_check.md`
   - `outputs/logs/stage1_data_check.md`
   - `outputs/logs/stage2_problem1_check.md`
   - `outputs/logs/stage3_problem2_check.md`
   - `outputs/logs/stage4_problem3_check.md`
   - `outputs/logs/stage5_problem4_check.md`
   - `outputs/logs/stage6_6_final_check.md`

## 三、推荐写作顺序

不要一次性生成全文。建议按以下顺序逐段生成，并在每一段完成后检查口径和数值：

1. 详细大纲
2. 模型假设与符号说明
3. 数据预处理
4. 问题 1 模型建立与求解
5. 问题 2 模型建立与求解
6. 问题 3 模型建立与求解
7. 问题 4 灵敏度与稳健性分析
8. 结果分析
9. 模型检验
10. 模型评价与改进
11. 问题重述与问题分析
12. 参考文献与附录说明
13. 摘要、关键词和题目优化
14. 全文一致性检查

摘要应最后写。原因是摘要中的数值、结论和风险判断必须能从正文、表格和图形中反查。

## 四、必须锁定的最终口径

大模型写作时必须始终遵守以下口径：

1. 消费约束主模型采用“收费服务等比例削减”。
2. 紧急救助始终公益免费，不参与消费约束、不计政府补贴，但计入直接成本和服务能力占用。
3. “刚需优先”只能写成补充对比、局限性或改进方向，不能写成主模型、核心创新点或摘要主线。
4. 问题 2 排序目标为：
   ```text
   max CR_srv
   -> max CR_eff
   -> max weighted_satisfaction
   -> max DR
   -> min construction_cost 或 min station_count
   ```
5. 年度利润不作为问题 2 选址排序目标，只作为基准价格下的测算指标。
6. 问题 3 每组候选价格必须重新计算价格满意度、小区分配、有效服务人次、补贴、题目口径利润率、年度净收益和可及性。
7. 利润率采用题目口径：
   ```text
   ServiceProfit_j = R_j - VC_j
   OC_j = 365F_j
   rho_topic_j = (ServiceProfit_j + G_j - OC_j) / (OC_j + epsilon)
   ```
8. 年度净收益单独定义：
   ```text
   A_j = 10000 * B_j / 20
   Net_j = R_j + G_j - VC_j - OC_j - A_j
   ```
9. 利润率硬约束只保留 `rho_topic <= 8%`，不得写成 `0 <= rho <= 8%`。
10. 若存在负利润率或负年度净收益，必须写“存在保本风险，需要政府统筹或财政兜底”，不得写成财务完全可持续。
11. 三类老人可及性必须使用最终有效服务人次 `E_{i,r,k}` 或由其汇总得到的指标。
12. `CR_srv` 是小区级聚合近似，需说明题目未提供个体服务获得记录，因此以小区为评价单元，并同时报告 `CR_eff` 和 `DR`。
13. 问题 4 的 S0-S4 情景均为完整重求解，不能只替换最终指标。
14. 140 万元预算情景不能简单写成“预算增加一定更好”；若扩张带来财务风险，应同时讨论覆盖收益和运营可持续性。

## 五、单次调用大模型的建议格式

每次调用大模型时，建议按以下结构组织输入：

```text
请使用以下提示词作为写作规范：
【粘贴对应提示词全文或相关章节】

请严格遵守以下最终口径：
【粘贴本文档第四部分】

本次只写：
【指定章节名称，例如：6.3 服务站选址与规模优化模型】

可用材料：
1. 最终方案摘录：……
2. 结果表格摘录：……
3. 图表索引摘录：……
4. 检查日志摘录：……

写作要求：
1. 不编造任何数值；
2. 所有结果必须引用给定表格或图；
3. 缺失结果用【待填：……】标注；
4. 不要写其他章节；
5. 输出为可直接放入论文的正式中文。
```

## 六、章节生成后的检查清单

每生成一节后，先检查以下问题，再进入下一节：

1. 是否把“等比例消费约束”误写成“刚需优先主模型”。
2. 是否把紧急救助误写成收费服务或补贴对象。
3. 是否把问题 2 的选址依据写成利润最大化。
4. 是否把利润率写成总成本口径。
5. 是否误写 `0 <= rho <= 8%`。
6. 是否混用了题目口径利润率和年度净收益。
7. 是否把负利润率或负净收益写成完全可持续。
8. 是否使用最终有效服务人次 `E_{i,r,k}` 计算可及性和老人支付额。
9. 是否把问题 4 写成只改参数、不重求解。
10. 是否所有数值都能在 `outputs/tables/` 或 `outputs/figures/` 中找到。
11. 是否每张图表的编号、标题、单位与 `outputs/figures/figure_index.md` 一致。
12. 是否出现“AI 提示词”“AI 生成”等不应进入论文正文的表述。

## 七、摘要提示词的使用时机

摘要优化提示词只在以下条件满足后使用：

1. 模型建立与求解部分已经完成。
2. 结果分析和灵敏度分析已经完成。
3. 题目口径利润率、年度净收益、补贴和可及性结果已经写入正文。
4. 图表编号和表格编号已基本确定。
5. 全文没有明显口径冲突。

使用摘要提示词时，应提供正文初稿、关键结果摘要、核心表格和图表索引。摘要中不得出现占位符，除非确实还有结果未确定；若出现占位符，应暂停定稿，先补齐对应结果。

## 八、最终定稿前检查

论文初稿完成后，应使用正文写作提示词中的“全文一致性检查”阶段进行复核。重点核查：

1. 摘要、正文、图表、附录中的模型口径是否一致。
2. 每个题目小问是否被明确回答。
3. 所有公式符号是否统一。
4. 所有结果数字是否可追溯到表格或图。
5. 利润率和年度净收益是否分开解释。
6. 问题 4 是否明确写成 S0-S4 完整重求解。
7. 附录是否只放入与主模型一致的代码说明、参数表和复现说明。

只有上述检查通过后，才进入最终排版和定稿。
