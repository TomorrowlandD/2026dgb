# 论文正文精简裁剪方案

## 1. 文档目的

本文档用于解决当前论文正文超过 25 页上限的问题，为后续 LaTeX 正文裁剪提供统一依据。精简工作的目标不是改变模型、结果或核心结论，而是在保持最终建模口径、关键公式、核心图表和数值结果一致的前提下，删除重复阐述、合并低信息密度段落，并将正文压缩到规定篇幅内。

本轮仅制定裁剪方案，不直接修改 `paper/sections/*.tex`。

## 3. 裁剪原则

### 3.1 必须保持不变的内容

后续压缩不得改变以下主模型口径和关键结果：

1. 问题一采用收费服务等比例削减规则；紧急救助公益免费，不参与消费约束、不计补贴，但计入直接成本和服务能力占用。
2. 问题二排序目标为 `CR_srv -> CR_eff -> weighted_satisfaction -> DR -> construction_cost`，年度利润不作为选址排序目标。
3. 问题三对每组候选价格重新计算 `S3`、小区分配、有效服务人次、补贴、题目口径利润率、年度净收益和可及性。
4. 题目口径利润率硬约束仅为 `rho_topic <= 8%`，不得改写为同时要求非负利润率。
5. 年度净收益与题目口径利润率分开定义和解释；存在亏损的站点或情景必须保留保本风险说明。
6. 问题四的 `S0-S4` 均为完整重求解，不得压缩为只替换最终指标的表述。
7. 三类老人可及性基于最终有效服务人次 `E_{i,r,k}` 计算。
8. 七张核心结果图、核心结果数值及图表引用关系原则上保持不变。

### 3.2 优先删除的内容类型

优先压缩以下低风险、低信息增量内容：

- 已由公式和图表清楚表达、随后又逐句复述的数值描述；
- 已在模型建立章节定义、在模型检验章节再次完整解释的口径；
- 问题重述与问题分析中对同一任务、同一约束的重复展开；
- “优点”和“改进方向”中与正文模型说明重复的论述；
- 表格逐行转写成连续文字、但没有新增结论的段落。

### 3.3 暂不优先裁剪的内容

以下内容不作为第一轮裁剪对象：

- 摘要：摘要单独占页且之后强制换页，精简摘要通常不能直接减少正文页数；
- 七张核心图：均用于支撑四个问题的结论；
- 问题三定价反馈闭环、利润率和年度净收益分离的核心公式；
- 附录：不计入正文 25 页限制。

### 4.2 符号表必须进入第一轮精简

当前总符号表包含 33 行，其中包括问题一缩减辅助量、问题二迭代中间量、问题三财务过程量和问题四变化度变量。该写法偏向程序/支撑文档，不利于竞赛论文正文阅读，也直接占用正文页数。

调整结论如下：

1. 符号说明从两张表合并为一张核心符号表。
2. 总符号表控制在 `20--25` 行以内，目标约 `22` 行。
3. 仅跨越多个问题、或直接承载论文结论的变量进入总表。
4. 只在单一小节使用的变量在公式首次出现处定义，不再进入总表。

预计仅符号表与假设的精简即可释放约 `0.8--1.5` 页。

### 5.3 模型假设

目标文件：`paper/sections/04_assumptions_symbols.tex`

当前八条假设均包含“假设内容、设置依据、对模型的影响”三个层次，文字结构过重。正文改为 `5--6` 条简明假设，每条不超过两句。

建议保留的六条假设方向：

1. 老人健康状态按自理、半失能、失能三类单向转移，新增老人进入自理状态。
2. 同类老人的服务需求由附件给出的平均需求频次表征。
3. 紧急救助公益免费，不参与消费约束和政府补贴，但计入成本与容量占用。
4. 小区仅在服务半径内选择综合满意度较高的服务站。
5. 站点能力按总有效服务人次统一约束，容量不足时同比例折减。
6. 覆盖率采用小区级聚合近似；模型内部连续计算，展示阶段再取整。

应删除的独立内容：

- “附件参数在规划期内可用”不再单独列为一条假设，可在数据来源说明中体现；
- 每条假设后的设置依据和影响分析不再逐项展开。
