# 嵌入式社区养老服务站建模流程图生成提示词

类型：中文数学建模论文方法总流程图，学术出版物风格，流程框图。

参考图作用：使用用户给出的图片作为版式与线稿风格参考；只借鉴“左侧纵向总主题 + 右侧四条横向问题流程链 + 黑白圆角矩形与箭头”的布局，不复制参考图的诗词研究文字。

画布与风格：
- 横向约 2:1 比例，纯白背景，无纹理、无阴影、无渐变。
- 黑色或深灰色细线，线宽统一；所有流程节点为白底圆角矩形，大小整齐、间距均匀。
- 箭头从左向右，四行严格水平对齐；左侧纵向总标题框与四行通过一条竖向分支线连接。
- 中文字体清晰、端正、印刷体，类似宋体或思源宋体；适合数学建模论文正文插图和黑白打印。
- 不增加图标、装饰、公式、数字、图注、页眉、logo 或水印。

版式：
- 左侧一个高的圆角竖框，框内文字从上到下竖排，逐字准确显示：
  “嵌入式社区养老服务站建设与优化问题研究”
- 右侧设置四行，行首依次为小圆角框：
  “问题一”
  “问题二”
  “问题三”
  “问题四”
- 每行从问题框向右连接四个圆角步骤框。

必须逐字准确显示的流程文字：

第一行（问题一）：
1. “数据预处理”
2. “三状态老人数量预测”
3. “等比例消费约束修正”
4. “实际服务需求输出”

第二行（问题二）：
1. “枚举站点位置与规模”
2. “预算及半径约束剪枝”
3. “满意度容量迭代分配”
4. “确定最优站点方案”

第三行（问题三）：
1. “候选价格搜索”
2. “重算满意度与有效服务量”
3. “补贴及利润率核算”
4. “三类老人可及性评价”

第四行（问题四）：
1. “设置S0-S4情景”
2. “各情景完整重求解”
3. “比较覆盖与财务指标”
4. “评价鲁棒性与运营风险”

生成约束：
- 所有文字使用简体中文，禁止乱码、错别字、额外标签与英文替代。
- 文字较长时允许在框内分成两行，但不得改写文字。
- 图形结构优先保证文字可读、节点不拥挤、箭头不断裂。
- 最终效果应与参考图同类：克制、清爽、线稿式、论文插图感，而非彩色信息图或商业幻灯片。
