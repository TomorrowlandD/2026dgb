# 嵌入式社区养老服务站建模总流程图 - 第一种增强版

## 任务类型

中文数学建模论文正文插图；学术流程图；参考用户提供的第一种黑白横向流程框模板。

## 核心目标

生成一张可直接用于 B 题《嵌入式社区养老服务站的建设与优化问题》论文“模型总体流程”部分的图。画面应准确体现四问的递进求解关系：

```text
需求预测与消费约束修正
-> 选址与规模优化
-> 定价、补贴与可及性评价
-> 情景完整重求解与风险分析
```

## 版式

- 超宽横向画布，比例约 2.4:1，纯白背景。
- 左侧为一个高的圆角矩形竖框，内置竖排总题目。
- 右侧为四条严格对齐的横向流程链，分别对应问题一、问题二、问题三、问题四。
- 左侧竖框右边使用一条黑色竖向主干及四条横向短箭头连接四个“问题”框。
- 每一行：一个较小的“问题”框，加五个依次相连的步骤圆角框。
- 每行步骤框大小统一、行间距一致；节点文字允许两行居中排版。
- 右侧每行最后的输出框通过极细的向下折线/短箭头指向下一行第一个实质步骤，表达四问递进输入关系，且不得穿过文字。

## 视觉风格

- 总体保持参考图的出版物线稿感：白底、深灰黑边框、细箭头、圆角矩形。
- 增强只体现在每行步骤框使用几乎不可见的低饱和浅色底：问题一浅蓝灰、问题二浅绿灰、问题三浅米黄、问题四浅紫灰；透明、克制，黑白打印仍清楚。
- “问题一/二/三/四”小框保持白底黑线。
- 中文字体清晰规范，使用宋体/思源宋体风格；字距规整，不能出现乱码。
- 不使用渐变、阴影、虚线大分区、图标、数据图表、公式、英文副标题、logo 或水印。

## 准确性要求

- 所有文字为简体中文，逐字准确，不能错写或替换。
- “满意度-容量迭代分配”中的连接符必须保留。
- “S0-S4”必须清楚，不得写成其他数字或字母。
- 问题三必须保留“反馈重算”和“净收益核算”的含义。
- 问题四必须保留“完整重求解”的表述。
- 不引入任何虚构数值、具体站点字母或模型结论。
