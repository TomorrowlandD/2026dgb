# 论文编写步骤 0 检查记录

## 执行步骤

本次执行《论文撰写严格规划清单》中的步骤 0：总约束确认与写作口径锁定。

本步骤不生成论文正文，不建立 LaTeX 工程，不修改模型结果，仅确认后续论文写作必须遵守的规则、材料状态和检查门槛。

## 已确认的写作工作流

1. 后续论文采用 LaTeX 优先工作流，先维护 `paper/` 下的 LaTeX 源文件，再由人工按竞赛 Word 模板转换为 Word 终稿。
2. 每次只生成指定章节或指定文档，不一次性生成全文。
3. 每一步完成后必须先做本步骤检查，检查未通过时不进入下一步。
4. 论文正文中不得出现“AI 提示词”“由 AI 生成”等内部过程表述。
5. 正文不写代码文件路径，代码说明、运行顺序和复现路径放入附录。
6. 摘要放在正文主体基本完成后撰写，且摘要中的结果必须能回溯到正文、表格或图。

## 已锁定的最终口径

1. 主模型采用“收费服务等比例削减”的消费约束需求调整。
2. 紧急救助公益免费，不参与消费约束、不计政府补贴，但计入直接成本和服务能力占用。
3. “刚需优先”只能作为补充对比、局限性或改进方向，不能写成主模型、核心创新点或摘要主线。
4. 问题 2 不使用年度利润作为选址排序目标；年度利润只作为基准价格下的测算指标。
5. 问题 2 分层排序目标固定为：`max CR_srv -> max CR_eff -> max weighted_satisfaction -> max DR -> min construction_cost`。
6. 问题 3 每组候选价格必须反馈到 `S3`、小区分配、有效服务人次、补贴、题目口径利润率、年度净收益和可及性。
7. 题目口径利润率定义为 `rho_topic_j = (ServiceProfit_j + G_j - OC_j) / (OC_j + epsilon)`。
8. 年度净收益 `Net_j` 与题目口径利润率分开解释。
9. 利润率硬约束只保留 `rho_topic <= 8%`，不得写成 `0 <= rho <= 8%`。
10. 若存在负利润率或负年度净收益，只能表述为存在保本风险，需要政府统筹或财政兜底，不能写成财务完全可持续。
11. 三类老人可及性必须基于最终有效服务人次 `E_{i,r,k}`。
12. `CR_srv` 是小区级聚合近似，论文中必须解释其近似原因，并同时报告 `CR_eff` 和 `DR`。
13. 问题 4 的 S0-S4 情景必须完整重求解，不能只替换最终指标。
14. 140 万元预算情景必须同时讨论覆盖收益和运营可持续性风险，不能简单写成“预算增加一定更好”。
